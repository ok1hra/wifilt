Pairing

Where your data is stored

QSO records are stored locally in this web browser on this device using the browser's IndexedDB storage.

The records are tied to the exact address used to open the ESP32 web interface (URL + port). If you open the same ESP32 using a different IP address, hostname, or port, the log may appear empty even though the records still exist under the original address.

Examples — each treated as a separate storage location:

  • http://192.168.1.50
  • http://192.168.1.50:80
  • http://wifilt.local

The ESP32 itself does not permanently store the QSO records, and there is no cloud backup. If browser storage is cleared or the device/browser is changed, the records may no longer be available.

How sync works

Synchronization happens in two steps:

  1. The two browsers exchange connection information through the ESP32. The ESP32 is only used to help establish the connection.
  2. After the connection is established, QSO records are transferred directly between the two browsers using WebRTC. The ESP32 does not relay or store the transferred records during synchronization.

A local network connection is required (for example the same Wi-Fi or LAN). Internet-based connections are not supported because no STUN/TURN servers are used.

Typical use cases

Two browsers connected to the same ESP32
Press Sync in both browsers. The ESP32 helps establish the connection, then the records transfer directly between the browsers.

Two browsers connected to different ESP32 devices
Enter the IP address of the other ESP32 in the field below so this browser knows which ESP32 to use for connection setup.

Press Sync on both devices. The first device waits, the second connects automatically.

FFTW 3.3.10
-----------
The js8-decoder.wasm module statically links the single-precision FFTW library.
Copyright (c) 2003, 2007-14 Matteo Frigo; Copyright (c) 2003, 2007-14
Massachusetts Institute of Technology.
License: GNU GPL version 2 or, at your option, any later version.
Because that binary is distributed, the FFTW source is part of this project's
Corresponding Source and is vendored rather than fetched: the unmodified
upstream archive is third_party/fftw/fftw3_3.3.10.orig.tar.gz, byte-identical
to Debian's fftw3 3.3.10-1 orig tarball. Its SHA256 is pinned in
prototype/js8-core-prototype/build-decoder-wasm.sh and toolchain/toolchain.lock,
and the build refuses to run if the archive is missing or does not match.
Upstream: https://fftw.org/

WSPR protocol
-------------
The WSPR encoder in data/wspr-core.js is original code, but the protocol
constants it implements are those of WSPR as defined by WSJT-X: the 162-bit
synchronisation vector, the K=32 convolutional polynomials, the interleaving
order and the callsign/locator/power packing.
Copyright 2001-2026 Joe Taylor (K1JT) and the WSJT-X development team.
License: GNU GPL version 3.
Protocol description this implementation was written from: docs/wspr.md
Upstream: https://sourceforge.net/projects/wsjt/

Bands × modes
Every column has its own filter, and all of them apply together. text finds the text anywhere in the cell, ignoring case (OK1). =text must match the whole cell (=20m does not find 2m or 12m). The number columns also take >5000, <10 and 14000-14100. Clicking a number in the statistics sets the matching filters. The address bar keeps the filters, so a link opens the same view.
